# Runtime Env Bundle demos

## Symfony 8 (FrankenPHP)

```bash
cd demo/symfony8
cp .env.example .env   # if needed
make up
```

- URL: http://localhost:8026
- Panel: http://localhost:8026/_runtime_env
- Default `FRANKENPHP_MODE=worker` (change in `.env` and recreate)

See [DEMO-FRANKENPHP.md](../docs/DEMO-FRANKENPHP.md).
